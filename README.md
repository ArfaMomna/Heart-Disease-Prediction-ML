## 📌 Project Overview
This repository contains the implementation of **Task 02: Build and Compare Machine Learning Models** for the AI/ML Devixo Internship. The primary goal is to perform a comprehensive comparative analysis of multiple classification algorithms on a real-world clinical dataset (Heart Disease Prediction).

The pipeline covers data preprocessing, feature scaling, training four distinct classification models, performance evaluation using standardized metrics, and hyperparameter tuning using `GridSearchCV`.
